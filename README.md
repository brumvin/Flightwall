# FlightWall

FlightWall is a Raspberry Pi wall-mounted aircraft display.

## Current build
Interactive browser test with:
- Main Flight screen focused on aircraft passing close to home
- Approaching / Overhead / Departing simulation
- Map
- Nearby aircraft
- Interesting aircraft
- Settings

The current build uses simulated aircraft. Live Wi-Fi aircraft data will be integrated after the interface and selection logic are validated.
